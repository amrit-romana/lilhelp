The questions worth asking.

By default it listens when you press the shortcut. Always-listening is a separate setting, it requires enrolling your voice, and the bar's placeholder changes so you can always tell which mode you're in.

Screen access is a macOS permission you grant during setup and can withdraw in System Settings at any time. "Watching" in the bar means it's ready for you, not that a recording is running.

That permission is requested during setup with an explanation of what it unlocks. Decline it and everything else still works — it just tells you what to do instead of doing it.

The Usage page shows cost per reporting window, request counts, input and output tokens, cache reads and typical duration, down to individual requests.

Destructive actions stop for a confirmation that expires after four seconds, and routines can require approval before each proposed step. Every request it has made is listed in History with the rules and memories it used.

The desktop interface is shared, but the call panel, screen recording and the menu-bar surfaces are macOS-native today. Windows parity is in progress.
