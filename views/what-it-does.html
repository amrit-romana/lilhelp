Routines

Work that happens without you in the room.

Scheduled and background jobs, with approvals where they matter and results waiting when you get back.

Each card shows name, schedule, prompt, latest result and whether you've read it. The available actions follow the state — Run now disappears while it's already running or waiting on you.

Approve, Reject, Pause, Turn back on, Run now, Mark results read, Delete. When it notices you doing the same work repeatedly it offers to save it as a routine — Yes, save it, or Dismiss.

Up to eighty runs are kept per routine, each with its time, preview, outcome and what it cost to run.
